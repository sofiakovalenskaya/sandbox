# ПАРА — анимация карт

Ролик длится 4,8 секунды: голубые карты заданий чередуются со светлыми картами шрифтов на розовом фоне #FF0056. Движение состоит из быстрых подъёмов, мягких замедлений и небольшого покачивания. Тайминг подъёма измерен по присланному видеореференсу; расположение карт адаптировано к согласованному формату 16:9.

- `PARA_Cards_Reference_4K.mp4` — 3840 × 2160, 60 кадров/с.
- `PARA_Cards_Reference_1080p.mp4` — 1920 × 1080, 60 кадров/с.
- `PARA_Cards_Keyframes.jpg` — контрольные кадры из готового MP4.
- `VIDEO_INFO.json` — параметры, контрольные суммы и результаты проверки файлов.

Карты взяты из исходного архива PARA ORIGINALS.zip. Текст и шрифтовые образцы не набирались заново. Перед рендером текстуры сверены с оригиналами по SHA-256. Скругления сохранены из исходных PNG. В обоих роликах по 288 кадров, звуковая дорожка отсутствует.
