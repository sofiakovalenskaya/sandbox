# ПАРА — круг из шести карт

3D-анимация в Blender: 5 секунд, 1920 × 1080, 60 кадров/с, розовый фон #FF0056.

В начале видна одна карта. Остальные пять появляются из-за неё, и все шесть расходятся в круг. Примерно к 1,6 секунды круг собирается, затем вся композиция медленно поворачивается в пространстве. У карт также есть небольшое собственное вращение.

Использованы все шесть PNG из нового архива пользователя. Файлы текстур скопированы без изменения байтов. Шрифты и макеты не перерисовывались. Рубашка — из оригинального SVG шрифтовых карт, предоставленного ранее.

Карты — замкнутые 3D-модели со скруглёнными углами, толщиной 0,45 мм, фаской, печатью с двух сторон и матовым бумажным материалом. Перспективная камера, мягкое освещение, без размытия глубины резкости.

Все семь изображений упакованы в `PARA_Circle_03.blend`. Проект открывается без внешних текстур. Пробел — воспроизведение, Numpad 0 — камера, Ctrl+F12 — рендер после сохранения в своей папке.

`01-single-card.png`, `02-circle.png`, `03-slow-turn.png` — контрольные кадры из финального рендера.

## Готовые файлы

- `PARA_Circle_03.mp4` — основной MP4 для просмотра: 5 секунд, Full HD 1920 × 1080, 60 кадров/с, H.264.
- `PARA_Circle_03_RGB.mp4` — RGB-мастер без потерь сжатия. Все 300 декодированных кадров точно совпадают с PNG рендера. Для просмотра подходит VLC, для монтажа — импорт в Blender.
- `PARA_Circle_03.blend` — исходная 3D-сцена с упакованными оригинальными текстурами.
- `Circle_03_keyframes.jpg` — контрольные фазы анимации.

Все кадры основного файла декодированы и проверены; длительность 5,000 с, 300 кадров при 60 кадрах/с.
