# ПАРА — третье промо в 4K, 60 кадров/с

Повторный рендер исходной 3D-сцены ролика «промо третье.mp4» в 3840 × 2160. Это новый рендер из оригинальных текстур, а не увеличение готового Full HD. Движения, камера, карточки, розовый фон и длительность 5 секунд сохранены. Частота исходного ролика уже составляла 60 кадров/с; интерполяция кадров не применялась.

- `PARA_Promo_Third_4K60.mp4` — обычный MP4 для просмотра, H.264, 3840 × 2160, 60 кадров/с.
- `PARA_Promo_Third_4K60_RGB_Master.mp4` — RGB-мастер без потерь для монтажа. Все 300 кадров сверены с пикселями нативного рендера.
- `PARA_Promo_Third_4K.blend` — исходная сцена с настройками вывода 4K и упакованными текстурами.
- `PARA_Promo_Third_4K_Keyframes.jpg` — контрольные кадры.
- `VIDEO_INFO.json` — параметры, контрольные суммы и результаты проверки.

Исходные PNG не менялись, текст и логотипы не набирались заново. Для ускорения Blender пропускал пустой фон за пределами границ объектов; полученные области помещены на полноразмерный розовый кадр пиксель в пиксель. Масштабирования этих областей нет. В обоих MP4 по 300 кадров и ровно 5 секунд, звука нет.
