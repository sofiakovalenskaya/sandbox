# ПАРА — эластичная типографика по референсу YES!

Готовые MP4: 60 кадров/с, 4,8 секунды — два одинаковых цикла по 2,4 секунды. Исходное видео проанализировано по кадрам: вытяжение вверх, изменение сужения, перекос влево, противоположный перекос и возврат в сжатую позу. Движение четырёх углов отслежено по записи; между позами восстановлены плавные переходы.

Логотип — оригинальные векторные контуры «ПАРА» из ранее предоставленного SVG. Розовый #FF0056, фон голубой #BDF9FD. Шрифты не подбирались и не перерисовывались. Деформация — намеренная часть анимации по запросу пользователя. Изображение растягивается и сжимается; это не полёт и не обычное вращение букв. Шум и зерно из сжатой GIF не добавлялись: контуры отрисованы чисто в высоком разрешении с двукратным сглаживанием.

- `PARA_Elastic.mp4` — основная версия, квадрат 1440 × 1440, с сильными растяжениями по геометрии референса. В паузах логотип тоже сплющивается в широкую полосу, как YES!.
- `PARA_Elastic_16x9.mp4` — та же анимация в горизонтальном кадре 1920 × 1080, для общего проморолика. Голубой фон расширен по бокам, графика сохраняет пропорции квадратной версии.
- `PARA_Elastic_Original_Proportions.mp4` — дополнительная адаптация: в паузах логотип возвращается к исходным пропорциям. Амплитуда деформаций подогнана к более высокой форме логотипа.
- `PARA_Elastic_RGB.mp4` — мастер основной квадратной версии, RGB 4:4:4 без потерь сжатия, для VLC или импорта в Blender. Все 288 декодированных RGB-кадров совпадают с PNG рендера по контрольным суммам.
- `Elastic_keyframes.jpg` — ключевые фазы основной версии.

В обоих циклах стык проверен: последняя нейтральная поза совпадает с первой. Основной файл H.264 подходит для обычного просмотра.
