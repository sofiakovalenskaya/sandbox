# СОЗДАЙ СВОЮ → ПАРУ — полёт отдельных букв

Новая версия: 4 секунды, 1920 × 1080, 60 кадров/с.

Каждая из 10 букв первой фразы и 4 букв второго макета движется отдельно: короткий подскок, поворот, быстрое ускорение, вылет и пружинящее торможение. На отметке 2 секунды розовый фон со светлой надписью сменяется светлым фоном с розовым словом «ПАРУ».

Контуры и заливки каждого пути взяты из оригинальных SVG без изменения. Применяются только перемещение и поворот цельных букв. Буквы не растягиваются, не скашиваются и не перерисовываются. Первый кадр, остановки и финал восстанавливают исходную композицию. Первый кадр и остановка первого макета проверены на точное совпадение пикселей с исходной композицией предыдущего ролика.

- `PARA_Create_Your_Pair_KINETIC.mp4` — основная версия для просмотра и презентации.
- `PARA_Create_Your_Pair_KINETIC_RGB.mp4` — RGB-мастер без потерь сжатия, для VLC или импорта в Blender. Контрольные суммы всех 240 декодированных кадров точно совпадают с PNG рендера.
- `KINETIC-check.jpg` — контрольные фазы движения.

Палитра оригиналов: розовый #FF0056, светлый #FFF0D5.
