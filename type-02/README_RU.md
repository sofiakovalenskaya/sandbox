# СОЗДАЙ СВОЮ → ПАРУ

Готовая анимация: 4 секунды, 1920 × 1080, 30 кадров/с.

- 0–2 секунды: оригинальная надпись «СОЗДАЙ СВОЮ», #FFF0D5 на фоне #FF0056.
- 2–4 секунды: оригинальная надпись «ПАРУ», #FF0056 на фоне #FFF0D5.

Буквы взяты непосредственно из присланных SVG. Контуры, цвета, взаимное расположение, исходные наклоны и пропорции букв не менялись. Анимирована вся композиция: небольшое равномерное масштабирование и вертикальное движение. Надписи не растягиваются по отдельным осям, буквы не деформируются. Между двумя кадрами — чёткая смена цвета и надписи на отметке 2 секунды.

`PARA_Create_Your_Pair.mp4` — основной файл для просмотра и презентации.

`PARA_Create_Your_Pair_RGB.mp4` — дополнительный RGB-мастер без потерь сжатия, с полной цветовой детализацией. Для просмотра подходит VLC, для монтажа можно импортировать в Blender. Все 120 декодированных RGB-кадров проверены по контрольным суммам: они точно совпадают с PNG рендера.

Векторные оригиналы отрисованы с двукратным сглаживанием для чётких контуров. PNG показывают оба макета в полном разрешении.
